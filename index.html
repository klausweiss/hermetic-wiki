index

  • hermetic is a static site generator for project-specific wiki.

  • Design goals

    • no config required, single binary that just works
    • opinionated, not many knobs to turn, intended to work for my use-case

  • Intended use-case

    • Documenting project implementation, as well as decisions made along the way.
    • Should help to get the overview of what's the current state of the project.

  • Supported features at a glance

    • basic markdown rich text
    • text search
    • images (viewing and pasting)
    • page mentions (aka linked references, see the bottom of this page)
    • journal
    • page relationships (through mutual parent, e.g. sample page 1 is related to see this page to understand how relationships are formed
    • TODOs
      • (e.g. TODOexplore how best to house AI-generated content↗)

  • Usage

    • Writing wiki

        1. Create a folder for storing project wiki, then run hermetic serve WIKI_PATH
        • you just ran the serve command
        1. Open the reported URL in the wiki.
        • The wiki is open in edit mode. You can now interact with and change it. Press ? to show keyboard shortcuts.
        • The files are saved as you change the contents.

    • Reading wiki

      • You can either use the edit mode for reading,
      • or render a read-only HTML version of the wiki using the build command with hermetic build WIKI_PATH.
      • The HTML version is a static website that can be hosted using most HTTP serves or hosting providers (e.g. GitHub Pages).
