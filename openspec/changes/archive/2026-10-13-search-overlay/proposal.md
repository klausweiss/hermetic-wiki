# Proposal

## Why

The header has grown to the site title, four links, and a 12rem search input, which no longer fits the 40rem header and wraps or overflows. The search input is the widest item, and it is only needed while searching.

## What Changes

- The header's search input becomes a search button (a magnifier icon) in the same place.
- Activating it, or pressing `/` or `Ctrl+K` (`Cmd+K`), opens a search dialog over the page, in the upper part of the screen, with the search field and the results as you type below it. It keeps today's behavior: up to 8 results, arrow keys and Enter to open one, Enter without a selection for `search.html?q=…`.
- `Escape`, clicking outside the dialog, or opening a result closes it, and focus returns to where it was.
- On `search.html` the dialog opens with the current query filled in.
- As before, nothing is shown without JavaScript or over `file:`.
- A site footer, with the link to the all-pages list and "Generated by hermetic", takes "All pages" out of the header. It is static HTML inside `<hermetic-sidebar>`: without the script it shows after the page's content, and with it the sidebar shows it at its bottom. `g p` still opens the all-pages list.

## Capabilities

### New Capabilities

None.

### Modified Capabilities
- `search`: "Search box and results page": a header button and a search dialog replace the header search box.
- `static-site-output`: "Site navigation": the header no longer links to the all-pages list; a site footer does. This builds on the requirement as changed by `add-graph-view`.
- `multi-pane`: new "Sidebar footer" requirement.
- `reader-ui`: "Keyboard shortcuts": `/` and `Ctrl+K` open the search dialog instead of focusing a box. This builds on the requirement as changed by `add-graph-view`, which must be archived first.

## Impact

- Frontend: `static/packages/search` (`<hermetic-search>` renders a button and a `<dialog>`), `static/packages/shortcuts` (detecting search, help text), the graph's Ctrl+F listener (leave the key alone while a dialog is open), and the search styles in `static/style.css`.
- Rust: `src/site/html.rs` moves "All pages" from the header to a footer inside `<hermetic-sidebar>`; the header still contains `<hermetic-search>`.
- Frontend: `static/packages/sidebar` moves the footer into the sidebar.
- No new dependencies.
